# Senior Dev Engineer References

This folder holds the specialist guidance that used to live in separate VisionCapture agent roles.

Use this folder with progressive disclosure:

1. Start with the assigned role and the project instructions.
2. Open the smallest relevant reference for the task.
3. Open another reference only when the work crosses that boundary.
4. Do not bulk-read every reference by default.

## Reference Map

- `codebase.md` - module map, source ownership, local docs, deprecated CLI boundary.
- `architecture.md` - design seams, dependency direction, deep modules, refactoring judgement.
- `quality.md` - build, tests, lint, QA, review, concurrency, coverage, and handoff gates.
- `app-agnostic.md` - enterprise app-agnostic audit rules and examples to avoid.
- `workflow-engine.md` - Core workflow execution, learning, scout, recovery, cache, step logic.
- `mcp.md` - HTTPServer, MCP tools, JSON-RPC, SSE, request/response contracts.
- `capture-ocr.md` - CaptureCore, OCRCore, screenshots, window discovery, PNG, Vision OCR.
- `interaction.md` - WebDriverAgent, tap/type/swipe/slider, readiness, retries, per-device state.
- `persistence.md` - SwiftData models, migrations, managers, contexts, queries.
- `llm-providers.md` - LLM provider adapters, prompts, streaming, keys, parsing.
- `macos-ui.md` - SwiftUI/AppKit/macOS shell, visual design, accessibility, windows, commands.
- `logs-permissions.md` - vision-logs, app logs, permissions, TCC, Simulator access.
- `docs-visuals.md` - docs, knowledge work, visual explainers, plans, diagrams.
