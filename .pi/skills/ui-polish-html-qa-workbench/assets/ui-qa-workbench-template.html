Export Acceptance Criteria

Acceptance criteria:
- Target container uses the same left gutter as the reference pattern.
- Selected, hover, focus, icon, label, badge/disclosure, and hit area move together as one object.
- Selected background starts at the same inset as comparable selected items.
- Hover and focus states use the same geometry as selected.
- Long labels truncate cleanly without shifting the object's geometry.
- Rendered UI is visually checked against the reference after implementation.

Export Review Note

Review focus:
- Compare before/after screenshots for the affected screen.
- Check default, hover, selected, focus, and long-text states.
- Confirm the changed code owns the container/background/hit area, not only a child element.
- Confirm no unrelated navigation or layout behavior changed.
- Note any checks that were schematic rather than measured.
