Qwen3.6-35B-A3B official integration

Implementation paused. The Gemma streaming design is understood. The next step is to finish the Qwen plan for reading and using the original weights.

Paused by Hebert · current requirement
Keep the downloaded approximately 72 GB Qwen model at its published BF16 precision. Shared working data stays in memory; selected experts are read from disk into a bounded cache. The 21.4 GB quantized conversion is withdrawn. Implementation is paused. NestMind Debug on iPhone 17 / iOS 26.5 is the authorized workflow target. VoiceOver and spoken replies are off. The phase tables below are historical version-1 evidence, not proof that the BF16 path is complete.
What needs to change in our codereviewed 2026-09-23

Precision means how much numerical detail is kept in the model’s stored numbers, called weights. BF16 is the original format of the downloaded Qwen weights. Some existing Qwen code expects numbers rounded into smaller formats. We need to adapt that code to read and calculate with the original weights.

Your 72 GB download is unchanged. Shared working data and a limited expert cache would stay in memory, with selected experts read from disk as needed. Keeping the original weights does not require loading the entire model into RAM.

The loader, expert byte layout and GPU calculations need changes. Shared-weight memory allocation also needs review. Original-precision Qwen output and actual memory use have not yet been verified. Read the source-code findings.

Document status: current decisions and evidence are updated. The replacement implementation plan is still unfinished. Updating this page does not resume implementation.

Verified Gemma streaming designsource review only

For every generated token, each of Gemma’s 30 layers chooses 8 of its 128 experts. A cached expert is reused. A missing expert is read from disk into one of the layer’s 16 default cache slots. The shared expert can run while those reads complete.

Memory also holds the common weights used by attention and routing, shared-expert weights, attention history and working buffers. The complete set of routed experts stays on disk. A model’s disk size is not its RAM requirement.

Current code review confirmed this path. No inference or fresh memory measurement was run. Qwen’s existing implementation assumes quantized expert data; its BF16 path still needs a revised plan. Implementation remains paused.
