What the revised design meansplanned behavior

BF16 is the original number format of the downloaded weights. The 26 shards total 71,903,776,776 bytes, approximately 72 GB. They stay in place. The proposed .gturbo registration contains identity and file locations, not another full set of weights.

The graphics processor keeps the common text weights in their original BF16 format. For each token and each of Qwen’s 40 layers, routing chooses 8 of 256 experts. Cached experts are reused. Missing experts are read directly from the official shards into bounded cache slots.

Each expert requires two file ranges: gate/up and down. Both must be ready before the cache marks that expert usable. Cancellation, a failed read or an active GPU operation must never expose a partially loaded expert.

Calculations can use FP32, a wider number format, while the stored weights keep their exact BF16 values. Original weights alone do not prove matching output. Independent numerical checks remain part of the plan.
