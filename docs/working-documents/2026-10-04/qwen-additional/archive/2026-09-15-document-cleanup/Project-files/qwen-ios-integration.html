09-06
Current architecture

Keep the device controls. Add Qwen beneath them.

The Mac app asks the model for a decision. The separate decode service runs the model. The existing host loop validates the exact app, Simulator and published accessibility action before calling VisionCapture.

Reuse
Verified downloads, resident storage, bounded expert reads, Metal device and queue, app shell and host action checks.
Add
Qwen loader, chat/tool codec, forward runner, recurrent memory, image encoder and model selection.
Current boundary
Simulator accessibility actions. Screenshots provide evidence. This plan adds no coordinate taps, scrolling or physical-device driver.
09-06
Metal work

Qwen needs different calculations, not just different sizes.

Thirty layers update recurrent memory. Ten use gated attention. Every layer selects eight of 256 experts. The detailed tasks specify exact tensor layouts, normalization, convolution, SiLU gates, image positions and independent reference fixtures.

New operations
Causal convolution and DeltaNet state update, Qwen gated attention, Qwen routing and shared-expert gate, separate output head and screenshot tower.
Source trap
Converted MLX norm weights may already include the offset used by the original model. Adding it twice silently corrupts results. The importer records the source convention.
Initial approach
Use simple bounded Metal dispatches and sequential recurrent processing first. Keep Gemma-specific fused calculations separate.
09-06
Conversation recovery

A failed reply must not repeat an iOS action.

Qwen overwrites recurrent memory as it reads tokens. Recovery must restore recurrent matrices, convolution history, attention state and positions together. A model-only retry reuses the already received tool result and never repeats its device action.

Memory estimate
The recurrent matrices require 60 MiB at batch one. One additional checkpoint adds another 60 MiB. These estimates exclude model weights, screenshots and scratch memory.
On failure
Restore a coherent checkpoint or stop with lost conversation state. New Chat clears model state and host action evidence.
