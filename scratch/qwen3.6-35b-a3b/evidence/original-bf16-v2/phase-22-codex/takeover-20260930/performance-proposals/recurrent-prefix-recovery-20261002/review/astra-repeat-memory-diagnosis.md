Metric semantics
The observed memory_pressure -Q output is a system-wide free percentage. It is neither the child's RSS nor the Activity Monitor pressure category. Apple distinguishes memorystatus available-page accounting, which includes reclaimable categories, from its separate pressure-notification subsystem: [XNU memorystatus documentation](https://github.com/apple-oss-distributions/xnu/blob/main/doc/vm/memorystatus.md#available-pages). This current public source does not establish the exact implementation/formula behind this installed macOS26 binary's printed percentage. Do not claim that29% is all unreclaimable memory, or that it is harmless filesystem cache.
For Metal, [Apple describes recommendedMaxWorkingSetSize](https://developer.apple.com/documentation/metal/mtldevice/recommendedmaxworkingsetsize) as guidance for resource/heap footprint, not a measurement of system free. Device currentAllocatedSize counts allocated Metal memory, not necessarily physically resident pages. [Apple's memory profiling talk](https://developer.apple.com/videos/play/wwdc2022/10106/) recommends proc_pid_rusage physical-footprint and lifetime-maximum counters for process accounting. These quantities must be recorded separately; none can be subtracted from another to derive precise GPU resident bytes.
